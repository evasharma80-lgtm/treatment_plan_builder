# AI Treatment Plan Builder

See the deployment guide from Claude for full click-by-click setup.

Quick reference:
1. Create a Supabase project, run supabase/schema.sql in the SQL Editor
2. Copy .env.example to .env.local and fill in your keys
3. npm install && npm run dev to test locally
4. Push to GitHub, import into Vercel, add the same env vars, deploy
